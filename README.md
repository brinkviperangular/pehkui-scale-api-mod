# Pehkui — Entity Scale API

[![Download Latest](https://img.shields.io/github/v/release/brinkviperangular/pehkui-scale-api-mod?style=flat-square&label=Download&color=brightgreen)](https://github.com/brinkviperangular/pehkui-scale-api-mod/releases/latest)
[![Forge](https://img.shields.io/badge/Loader-Forge-orange?style=flat-square)](https://files.minecraftforge.net/)

An API and mod for scaling entities, blocks, and items to any size using NBT attributes.

![Pehkui — Entity Scale API Preview](https://cdn.modrinth.com/data/t5W7Jfwy/icon.png)

## Features

- Scale any entity from 0.1x to 10x default size
- Per-axis scaling for stretch and squash effects
- Attribute-based — compatible with other stat mods
- Persistence across relog and dimension change
- Used by Mutable Tooltips, Jam, and size mods

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your Minecraft version
2. Download the JAR matching your exact Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** See download table above
